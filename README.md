# 中国创新药 · 热门靶点演进图谱

一张可交互漫游的「中国创新药热门靶点」公开数据科普图谱 —— 看代表性赛道如何从 **fast-follow（跟随）** 走向 **first-in-class（原创）**。

🔗 在线体验：**https://cn-innopharma-roamer.pages.dev**（手机端友好）

> 公开资料整理 · 行业科普图谱 · **不构成投资或医疗建议** · 不代表任何雇主

---

## 这是什么

- **公开数据整理的行业演进图谱**（科普向），不是竞争情报分析。所有公司一律作为中性数据节点，每个节点都带公开来源。
- 覆盖 **6 大领域 · 28 个代表性热门靶点**：肿瘤免疫 / 实体瘤靶向 / ADC / 血液肿瘤与细胞治疗 / 自身免疫 / 代谢与心血管。
- 主线 = **跟随 ↔ 原创** 光谱（横轴；冷青=快速跟随 me-too，暖金=原创 first-in-class）。`fic` 字段为面向科普的编辑性简化，非监管/学术定义。

## 怎么用

- **格局**（默认）：散点全景。滚轮/双指缩放、拖拽平移、点任意药看公司 / 靶点 / 原创度 / 关键年份 / 公开来源。
- **演进**：按年份看每个赛道从跟随到原创的演进曲线。
- **巡游**（`?tour=1`）：电影级自动巡游 —— 穿梭节点星系、俯冲到代表性药物的详情卡（用于宣传片，确定性可逐帧渲染）。

## 数据与口径

- 仅收录**公开数据**（NMPA 公开获批 / 公司公开公告 / 公开新闻），每条带来源。
- 口径为「中国创新药」：以中国原研或中国主导研发为主；纯进口品种不纳入。
- 原创度按「全球首创 → 顶档」的中立规则编辑性标注，避免偏袒任何一家。
- 数据见 [`public/data.js`](public/data.js)。

## 技术

- 纯前端单页：`public/index.html`（Canvas 散点 + SVG 演进 + 巡游引擎）+ `public/data.js`（数据集）。
- 部署：Cloudflare Pages（`deploy.sh`，需自备 `CLOUDFLARE_API_TOKEN`）。
- 无构建步骤，`public/` 目录即可静态托管。
